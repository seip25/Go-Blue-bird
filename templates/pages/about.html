Sobre Go Blue Bird

Este kit de inicio está diseñado para eliminar el boilerplate al lanzar nuevos servicios web o aplicaciones monolíticas en Go.

Resumen de la Arquitectura

  • Gin Web Framework: Enrutamiento HTTP de alto rendimiento y pipeline de middleware.
  • Core Package: Paquetes auxiliares modulares para respuestas, validación, hash y solicitudes.
  • Dotenv Config: Gestión de entornos flexible que admite modos de desarrollo y producción.
  • Smart CLI: Utilidades integradas para cambiar el nombre del módulo del proyecto e inspeccionar rápidamente la base de datos.
