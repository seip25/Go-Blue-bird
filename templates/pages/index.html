⚡ Kit de Desarrollo en Go para Producción

Arquitectura modular de alto rendimiento para APIs y aplicaciones web monolíticas en Go con assets y plantillas embebidas.

Rendimiento Nativo 🚀

Enrutamiento ultrarrápido con Gin, modo Release y concurrencia por Goroutines.

Binario Embebido 📦

HTML, CSS y JS compilados directamente dentro de un único ejecutable sin dependencias.

Base de Datos Resiliente 🗄️

Soporte multi-driver para SQLite (WAL mode), MySQL y PostgreSQL con reintentos automáticos.

In-Memory RAM Cache ⚡

Caché en memoria sub-milisegundo con TTL y sincronización segura mediante RWMutex.

Validación y Seguridad 🛡️

Middlewares de CORS, recuperación de pánico, hash Bcrypt y validación de esquemas JSON.

Herramienta CLI 🛠️

Herramienta CLI para renombrar módulos, inspeccionar base de datos y generar builds con systemd/nginx.
